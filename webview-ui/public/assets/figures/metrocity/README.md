# Metro City character layers

Source: "Metro City" and "Metro City 2.0" by JIK-A-4, https://jik-a-4.itch.io/metrocity

License: Creative Commons Zero v1.0 Universal (CC0), as stated in the itch.io
page metadata ("Asset license: Creative Commons Zero v1.0 Universal"). The
author also writes "You can use it as you wish". No attribution is required;
this note is kept as a courtesy.

`server/src/figures/` composes these layers into office characters, seeded by
an agent's session name. Files (original names in parentheses):

- `body.png` (CharacterModel/Character Model.png): 6 skin tones, one per row
- `hairs.png` (Hair/Hairs.png), `hairs2.png` (MetroCity 2.0/Hair.png)
- `outfit1,2,4,5,6.png` (Outfits/OutfitN.png); Outfit3 is underwear only and left out
- `suit.png`, `suit1.png` (MetroCity 2.0/Suit.png, Suit1.png)

Every sheet uses 32x32 cells, 24 columns: 0-5 facing down, 6-11 right,
12-17 up, 18-23 left.
